Peta Properti is an interactive property search portal that aggregates housing data from Sikumbang Tapera — a government housing registry — and presents it visually on an interactive map. Users can explore, filter, and search for available properties based on location, giving them a spatial understanding of property availability across regions.

The platform combines a geospatial backend with a modern map-based frontend to make property data more accessible and intuitive to navigate.

#### My Responsibilities & Contributions

1. Designing and building the Golang backend with PostGIS to store and query geospatial property data from Sikumbang Tapera.
2. Implementing geospatial queries (bounding box, radius search) to efficiently filter properties by map viewport.
3. Building the interactive map interface using MapLibre GL on Next.js, rendering property markers and clusters dynamically.
4. Integrating the Sikumbang Tapera data pipeline to ingest and normalize property records into the database.
5. Designing the search and filter UI to allow users to narrow results by location, property type, and other attributes.
6. Ensuring the application is responsive and performs well across desktop and mobile devices.
