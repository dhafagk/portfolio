Sahabat Insurance is company profile and utilities website for insurance provider, presenting product info, branch/company profile pages, and self-service tools such as workshop (bengkel) locator, all backed by Payload CMS for content management.

Site pairs Next.js frontend with Payload CMS + Postgresql, letting non-technical team update pages, navigation, and collections (branches, workshops) without code changes.

#### My Responsibilities & Contributions

1. Built Next.js frontend consuming Payload CMS collections for dynamic pages, navigation, and content blocks.
2. Set up Payload CMS with Postgresql adapter, including collections and migrations for structured content.
3. Developed workshop/garage locator page (`/garage-list`) with search and category filtering.
4. Wrote and maintained database migrations for schema changes (navbar config, collection fields).
5. Improved UI/UX of listing and table components — search, filtering, category tags.
